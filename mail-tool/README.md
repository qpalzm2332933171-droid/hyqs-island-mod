# 邮件定制工具(网页版)

**双击 `index.html` 用浏览器打开即可, 纯前端离线运行, 不联网、不上传任何数据。**

## 功能

- 321 种物品的**图形化选择**(带图标、名称搜索、ID 搜索);
- 按官方分类筛选(工具/食物/材料/药品/特殊/杂物 + 货币);
- 一键全选 / 清空 / 按分类全选;
- 每件数量、附带贝壳、邮件标题、正文、发件人;
- **到期时间选择器**(支持"永久"/自定义天数);
- 自动计算 `token`(游戏同款 MD5 公式), 生成可直接粘贴的 `querymail1` 响应体;
- 内置 `100005`(时之砂)数量上限 9 的强制保护 + 红字警告;
- 一键复制 JSON。

## 使用步骤

1. 右上角填**你自己的 UID**(游戏内可查, 必须是数字);
2. 选物品 -> 设数量 -> 设贝壳/到期时间;
3. 点"生成响应体", 复制右侧 JSON;
4. 到 Reqable 新建"响应体重写"规则, 匹配 `/Logic/user/querymail1`, 粘贴即可(见 README 第 5 章)。

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 界面 + 逻辑(单文件, 无依赖) |
| `items.js` | 321 条物品数据: id / 名称 / 繁体名 / 类型 / 权重 / 价值 / 是否有图标 |
| `md5.js` | 游戏同款 MD5 实现(直接用游戏的 hex_md5 逻辑) |
| `gen.js` | 响应体结构 + token 计算 |
| `icons/<id>.png` | 从游戏图集里切出来的物品图标 |

## 注意

- `to_user` 必须是**你自己的 UID**, 否则 token 不匹配(而且邮件也不该给你);
- 改了任何参与 token 的字段都必须让工具重新算 token(工具会自动算);
- 一次别刷太狠, 别发 >9 的 100005, 详见 README 第 7 章。

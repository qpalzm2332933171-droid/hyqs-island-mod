# 反外挂与封号机制分析 (荒野日记:孤岛 1.9.0.0)

> 本文是**逆向分析原文**; 想要"手把手操作步骤"请看 [../README.md 第 7 章](../README.md#7-教程二封号机制与用-reqable-解各种封号4015-1--4015-6)。
> 一句话结论: **4015-1 ~ 4015-6 都是客户端本地弹窗**(进 Main 场景时 `_checkIsCheated()` 读存档里的标记),
> 清掉标记 + 上传即可恢复, 不是真封号; 真封号是 login 返回 `invalid`/`1001`, 本地无解。

分析时间: 2026-10-06 凌晨 | 账号 uid=1000000000000 | 结论: 弹窗为**客户端本地触发**, 已清除标记, 账号未被真正封禁

## 1. 封号弹窗的触发地点

弹窗由客户端 `_checkIsCheated()` (进入 Main 场景时调用) 以及各作弊发生点立即弹出。标题后缀对应当地 base 数据里的非法标记:

| 标题 | 条件键 | 含义 |
|---|---|---|
| 错误4015 (n/a) | 登录响应 `invalid` | 服务器真封号 (仍可登录时 likely 不会出现; errorCode 1001) |
| 4015-1 | main.js 文件 md5 | 热更文件被改 |
| 4015-2 | base.cheatAchievement / base.achieve_fake_profile | 成就作弊 |
| 4015-3 | base.cheatBuildProducts | 建筑产物作弊 |
| 4015-4 | base.cheatGoOutMax | 远行作弊 |
| 4015-5 | base.coin.adCoin.illegal | 广告币作弊  <- 本次中招 |
| 4015-6 | base.cheatSelectGift | 礼包选择作弊 |

弹窗按钮确定后 `HYCommon.restartGame` 重启 -> 每次进主场景又弹 -> 表现为"封号"(实为本地循环弹窗, 无法游玩)

### 工具修改 (deliverables/mail-tool/index.html)

## 附: 用 Reqable 复现/验证清零(操作版)

**A. 断点法(跟着游戏自己的请求走, 最稳)**

1. Reqable -> 断点(Breakpoint) -> 新建:
   - URL 匹配: `*Logic/user/updatedata`
   - 勾选 **请求(Request)**;
2. 进游戏, 等游戏自动存档(进存档 20-40 秒内一般会发一次 `updatedata`);
3. 断点命中后, 在请求体里改两个参数:
   - `modify` = `{"base.coin.adCoin.illegal":0}`(URL 编码: `%7B%22base.coin.adCoin.illegal%22%3A0%7D`)
   - `sign` = `md5("apsdfAJOJ(#@&($0809283JLJOOJ" + base64(modify原串) + uid)`
     -> 用 `mod/tools/verify_sign.py` 里同样的算法算, 或直接跑 `python mod/tools/unban.py` 只取它打印的 sign;
4. 放行, 服务器返回 `errorCode: 0` 即成功;
5. 完全重启游戏 -> 弹窗消失。

**B. 脚本法**

```bash
python mod/tools/check_flags.py --account-id <accountId> --openid <openId>   # 先看现在有哪些标记
python mod/tools/unban.py --uid <UID> --account-id <accountId> --openid <openId> \
                          --logic-token <logicToken> --all --verify          # 一次清光 + 复查
```

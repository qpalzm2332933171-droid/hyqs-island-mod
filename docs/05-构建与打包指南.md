# 构建与打包指南

## 1. 目录约定

```
<repo>/game-source/project.dec.js     明文游戏逻辑(打包用)
<repo>/mod/js/mod_native.js           MOD 主体
<repo>/mod/java/com/hymod/*.java      Java 原生菜单
<repo>/mail-tool/icons/*.png          物品图标
<repo>/work/apk_dec/                  apktool 解包后的工程(自己生成)
<repo>/work/apktool/apktool.jar       apktool(自己下载)
<repo>/work/build/                    中间产物
<repo>/dist/                          最终 APK
```

## 2. 一次性准备

```bash
# 1) apktool
mkdir -p work/apktool && curl -L -o work/apktool/apktool.jar https://bitbucket.org/iBotPeaches/apktool/downloads/apktool_2.9.3.jar

# 2) 解包目标 APK(保留原 dex, 只解资源)
apktool d -f -s -o work/apk_dec 荒野日记孤岛.apk

# 3) 打 manifest 补丁
python mod/tools/patch_manifest.py

# 4) 环境变量(可选)
set ANDROID_SDK_ROOT=D:\Android\AndroidSDK
set JAVA_HOME=C:\Program Files\Eclipse Adoptium\jdk-21.0.8.9-hotspot
pip install xxtea
```

## 3. 日常构建

```bash
# 只改 JS: 重建 jsc 并放回工程(最快, 几秒钟)
python mod/tools/build_mod.py --deploy --check

# 改 Java: 重编译 dex
python mod/tools/build_dex.py

# 全流程: jsc -> 图标 -> apktool b -> 注入 dex -> zipalign -> 签名
python mod/tools/build_apk.py
```

## 4. 关键步骤说明

| 步骤 | 做了什么 | 为什么 |
|---|---|---|
| jsc 打包 | `zip(encrypt.js)` 再 XXTEA 加密 | 游戏 `jsb` 加载的就是这个格式, key = `ebf83d12-bc75-4b` |
| 注入 `classes2.dex` | 直接把 dex 塞进 APK zip | apktool 回编译不会管 dex; 用 zip append 最简单 |
| `zipalign -p 4` | 4 字节对齐 | Android 11+ 强制要求, 否则装不上 |
| `apksigner` | v1+v2+v3 签名 | 必须先 zipalign 再签名, 顺序反了 v2 签名会失效 |
| provider | 空 ContentProvider | 借进程启动时机做注入 + 覆盖热更文件 |

## 5. 发布两个 ABI 的包

游戏本体只有 `arm64-v8a / armeabi-v7a / armeabi / x86` 四个 so(没有 x86_64)。
要拆包只保留一个 ABI:

```python
import zipfile, shutil
SRC, KEEP = "dist/荒野日记孤岛_MOD.apk", "lib/arm64-v8a/"   # x86 版就写 "lib/x86/"
dst = SRC.replace(".apk", "_arm64.apk")
shutil.copyfile(SRC, dst)
with zipfile.ZipFile(dst) as z:
    names = [n for n in z.namelist() if n.startswith("lib/") and not n.startswith(KEEP)]
    # 用 zipfile 无法直接删条目, 实际做法: 读出所有条目重建 zip, 或直接用 7z -d
print("需要删除的条目:", names[:5], "...共", len(names))
```

**注意: 删了 lib 里的文件后必须重新 zipalign + apksigner**(改动会破坏 v2 签名)。
本仓库 Release 里的 arm64 / x86 包就是这么拆的。

## 6. 常见构建错误

| 报错 | 原因 |
|---|---|
| `not a zip after xxtea` | key 不对, 或文件不是 jsc |
| apktool `b` 失败 | `apktool.yml` 里的 versionCode 不合法 / 资源损坏, 用 `-s` 解包的不能直接 `b`(需要 dex) |
| `INSTALL_PARSE_FAILED_NO_CERTIFICATES` | 忘了签名 |
| `INSTALL_FAILED_INVALID_APK` | 没 zipalign |
| 装完闪退 + `ClassNotFoundException: com.hymod.*` | classes2.dex 没注入成功 |

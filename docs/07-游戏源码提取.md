# 游戏源码提取(.jsc 解密)与调试

## 1. 为什么是 .jsc

Cocos Creator 的 JSB 工程把 `project.js` 编译/加密成 `project.jsc`。这个游戏用的是:

```
jsc = XXTEA( zip( ["encrypt.js"] ) ,  key )
key = "ebf83d12-bc75-4b"        # 16 字节
```

路径: `assets/src/project.jsc`(另有 `jsb_polyfill.jsc` / `settings.jsc`, 一般是明文 zip)。

## 2. 静态解密(推荐)

```bash
pip install xxtea
python mod/tools/jsc.py unpack work/apk_dec/assets/src/project.jsc project.js
```

`jsc.py` 的核心就三行:

```python
blob = open(path,"rb").read()
z = xxtea.decrypt(blob, b"ebf83d12-bc75-4b")
js = zipfile.ZipFile(io.BytesIO(z)).read("encrypt.js")
```

加密方向(`pack`): 打包成 zip(条目名固定 `encrypt.js`, 时间戳固定 1980-01-01)再 XXTEA 加密。

## 3. 动态解密(Frida, 用于 key 未知或被改)

```bash
pip install frida
python mod/tools/dump_xxtea.py --pkg com.dygame.hyqs.nearme.gamecenter --out dump
```

脚本会:

1. `frida.spawn` 起游戏;
2. `Interceptor.attach` 到 `libcocos2djs.so!xxtea_decrypt`;
3. 每次调用把**返回值 + 输出长度**dump 出来, 存成 `dump/xxtea_XX_NNNN.bin`;
4. 这些 bin 里 `PK\x03\x04` 开头的就是 zip, 解出来就是明文 JS。

> 这也是本仓库 `game-source/project.raw.js` 的来源之一。

## 4. 美化

63260 行的单文件 JS 直接用编辑器看很痛苦, 用任意 JS beautifier:

```bash
npx js-beautify project.js -o project.beauty.js
# 本仓库的 game-source/project.beauty.js 即美化后的版本, 文档里的行号都指它
```

## 5. 运行时调试

**JS 侧**

- 游戏是 Cocos JSB, 可以直接 `console.log`, 用 `adb logcat` 看:
  ```bash
  adb logcat | findstr /i "hymod jsb cocos"
  ```
- 也可以挂调试器: `assets/script/debugger/` 里是 Cocos 自带的 devtools 调试器;
- 最方便的是直接用 MOD 自己写日志(参考 `mod/js/mod_native.js` 的 `log()` / `T()`)。

**Java 侧**

- `ModBridge` 里 `Log.i("HYMOD", ...)`;
- 抓所有 mod 日志: `adb logcat -s HYMOD:*`

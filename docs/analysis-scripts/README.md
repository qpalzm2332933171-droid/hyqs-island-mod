# 分析脚本存档

这些是当初做逆向时用到的**一次性脚本**, 保留下来是为了:

1. 说明每一步结论是怎么得到的(可复现);
2. 给后面想分析**别的** Cocos/JSB 游戏的人当模板。

| 前缀 | 用途 |
|---|---|
| `r*.py` | 按正则从 project.js 里捞特定代码片段(改行号就能复用) |
| `research*.py` | 查科技树/皮肤/天赋的上限规则 |
| `find_cats*.py` | 找物品分类(官方分类字段) |
| `patch_*.py` | 迭代式修改游戏 jsc / 菜单 / HTML 工具的补丁脚本 |
| `scan_*.py` | 扫描作弊标记键名 |
| `dump_*.py` | dump sqlite / lua 菜单 / 文本 |
| `gtest.py` / `deploy.py` | 实机启动 + 截图 + 部署测试 |
| `attr_ids.py` / `roleinfo.py` / `skinfo.py` | 属性 ID / 角色 / 皮肤信息整理 |

> 注意: 这些脚本里有大量硬编码路径, 是**当时环境**的写法, 仅供参考。
> 正式可用的是 [`../../mod/tools/`](../../mod/tools/) 下整理过的版本。
